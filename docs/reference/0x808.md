## 1. 它是什么

**鼓机 / 步进音序器 / 合成器工作站**。不是 tracker，也不是 DAW——是 16 轨 × 16 step 的鼓机网格 + 钢琴卷帘 + 合成器 + 采样浏览器 + 混音台，另有 GTK4、VST3、CLAP 三个前端。

正因为它是"MIDI 步进音序器"，才有走带、通道、时间轴、主题、撤销栈这些我们需要的载体。

## 3. 对我们最有用的几个事实

### 3.1 音频接口天然可替换（关键）

```c
void sq_engine_process(sq_engine_t *engine, float *output /* interleaved L,R */, uint32_t num_frames);
```

定义在 `src/engine/engine.c:315`。已被 **4 个不同宿主以 4 种方式调用**：

| 宿主 | 文件:行 | 方式 |
|---|---|---|
| 独立 GUI | `src/standalone/main_gui.c:143` | **推送式**（`SDL_QueueAudio`），非回调 |
| 独立 CLI | `src/standalone/main.c:40` | miniaudio 拉取回调 |
| GTK 前端 | `src/gui_gtk/main_gtk.c:81/123` | 推送式 |
| VST3/CLAP 插件 | `src/plugin/plugin.c:801` | 宿主驱动 |

→ **把 `main_gui.c:143` 改成从 libvgm 拉帧，约 1 人日。** 这是选它当壳最硬的理由。

音频参数（`main_gui.c:177-207`）：44100 Hz 硬编码、`AUDIO_F32SYS`、2 声道、`AUDIO_CHUNK_FRAMES 512`、`AUDIO_TARGET_QUEUED 4096`。

### 3.2 走带是 BPM/16 分驱动（要绕过）

`sq_transport_t`（`src/engine/engine.h:151-165`）：

```c
double bpm; double current_beat; uint64_t sample_position; bool playing;
sq_play_mode_t mode;  // MODE_PATTERN / MODE_SONG / MODE_PERFORM
int current_pattern, current_step, current_section, queued_section;
float swing;
```

`transport_advance(tr, sample_rate, num_frames, pattern_length)` 在 `src/engine/transport.c:132`，`STEPS_PER_BEAT 4`（固定 16 分音符），swing 在 `beat_to_step()` 里把奇数 16 分音符延后。

→ **VGM 模式整体绕过，不改 `transport.c`**（见 `RULES.md` F8）。

### 3.3 没有"寄存器"概念

数据模型只有 step/track/voice：

- `sq_step_t{velocity, pitch_offset, note, probability, retrigger, length, micro_offset, param[4]}`（`engine.h:83-92`）
- `sq_track_t`（`engine.h:102-121`）
- `sq_voice_t{sample_index, position, rate, velocity, volume, pan, ...}`（`engine.h:66-79`）

全仓 `grep -n 'getRegisterPool\|reg_state\|shadow'` = **0 命中**。

→ **VGM 视图只能新建，不能复用 `drum_grid.cpp` / `piano_roll.cpp`**（见 `RULES.md` F9）。

### 3.4 没有 VGM

全仓 `grep -ril vgm . --exclude-dir=.git` = **0 命中**（连 README/docs 里都没有）。

导入格式：`.sqproj`（JSON）、WAV/MP3/FLAC、`.sf2`。导出：WAV/MP3/FLAC。

### 3.5 面板系统是硬编码 float

`src/app/sq_app.h:63-70`：

```c
typedef enum {
    SQ_PANEL_BROWSER, SQ_PANEL_MIXER, SQ_PANEL_PIANO_ROLL,
    SQ_PANEL_KEYBOARD, SQ_PANEL_SETTINGS, SQ_PANEL_COUNT
} sq_panel_t;
```

只有 5 项，布局是 `gui.cpp:800-960` 的硬编码 float 计算，**没有 docking**。

`CLAUDE.md` 的 "Frontend Parity" 硬性要求 ImGui 与 GTK 两份前端行为一致 → 加面板理论上要做两份。**VGM 视图明确只做 ImGui 一份（刻意例外，已记录）。**

## 5. 构建

```bash
/d/msys64/usr/bin/bash.exe -lc "cd /e/working/zcode-projects/VGM_Studio/0x808 && \
  cmake -S . -B build -G Ninja && ninja -C build"
```

依赖状态：全部 vendored 在 `deps/`（imgui 1.91.8、rtmidi、glad、cplug、shine、miniaudio.h、dr_*.h、tsf.h、cJSON）。`deps/SDL2-2.30.12/` 里的 `x86_64-w64-mingw32/lib/` **只有 `.la` 和 `cmake/`，没有 `.a`** → 走 `find_package(SDL2)` 会用到 MSYS2 系统 SDL2（2.32.10），这是可行的。

### 已验证的问题：`sequencer_gui` 链接失败

```
libimgui.a(imgui_impl_sdl2.cpp.obj): undefined reference to `SDL_IsGameController'
libimgui.a(imgui_impl_sdl2.cpp.obj): undefined reference to `SDL_GameControllerOpen'
libimgui.a(imgui_impl_sdl2.cpp.obj): undefined reference to `SDL_SetCursor'
libimgui.a(imgui_impl_sdl2.cpp.obj): undefined reference to `SDL_ShowCursor'
libimgui.a(imgui_impl_sdl2.cpp.obj): undefined reference to `SDL_WarpMouseInWindow'
libimgui.a(imgui_impl_sdl2.cpp.obj): undefined reference to `SDL_SetClipboardText'
... (GameControllerGetButton / GetAxis 大量重复)
```

**原因**：静态库单趟解析顺序——`libimgui.a` 排在被 `SDL2_LIBRARIES` 之前，imgui 里的 SDL 符号在被引用时已经"不够用"了。叠加 `-static -static-libgcc -static-libstdc++ -mwindows` 与动态 `SDL2.dll.a` 混用。

**修法（按优先级）**：

1. `0x808/CMakeLists.txt:292` 起的 `sequencer_gui` 链接段，把 `${SDL2_LIBRARIES}` 移到 `sq_gui sq_midi` **之前**（即 SDL2 在后、imgui 在前不行，要 SDL2 在引用者之后）—— 实际正确顺序是 `sq_gui sq_midi imgui ${SDL2_LIBRARIES} ${SQ_OPENGL_LIB}`；
2. 或加 `-Wl,--start-group ${SDL2_LIBRARIES} imgui -Wl,--end-group`；
3. 去掉 MINGW 分支的 `-static`，或改用静态 `libSDL2.a`。

其它已编出的产物（`libsq_engine.a` / `libsq_gui.a` / `libsq_app.a` / `libsq_midi.a` / `libimgui.a` / `librtmidi.a`）都正常。

## 7. 结论

**选它当壳。** 判据"最容易编译、最容易装配"逐项打分：

| 判据 | 0x808 |
|---|---|
| 许可能直接改 | ✅ MIT |
| 依赖本地已有 | ✅ 全 vendored |
| 本机可编 | ✅ 只需修一处链接 |
| 有走带/通道/时间轴 | ✅ |
| 换音频源成本 | ✅ 一处函数 |
| 体量 | 3.5 万行（对比 Gridline 46.5 万、furnace 30 万） |

**最大障碍不是代码，是语义错配**：它的数据模型里没有"寄存器"，所以 VGM 视图必须新建；只复用壳（SDL+ImGui 主循环、toolbar、theme、undo、文件对话框）。
