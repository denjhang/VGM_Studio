# 界面设计

> 本文件只讲**界面长什么样、怎么交互、复用哪个库的哪段代码**。
> 架构 → `ARCHITECTURE.md`；数据结构 → `DATA-MODEL.md`；目标 → `GOAL.md`。

---

## 1. 硬性决定

**界面形态 = 步进音序器 / 钢琴卷帘式的横向音条布局。**

明确否定的做法：Furnace 那种纵向 tracker 表格（时间向下、通道向右、每行一个格）。原因：**tracker 表格强制"一个事件一个格"，而无损时序对不上格**。用表格就等于在 UI 层强行量化，用户看到的位置是假的。

**界面时间轴 = 采样数**，不是行、不是拍、不是 tick。缩放只改"像素/采样"比例，不改任何数据。

## 2. 主窗口布局

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 走带条                                                                      │
│ ▶ ■ ⏸ ⏮ ⏭   采样 00:00:01.234 / 00:00:05.692   [网格: 关 ▾]  [缩放 ▬●▬]   │
├──────────────┬─────────────────────────────────────────────────────────────┤
│ 通道列表      │ 时间轴（横向，像素 ↔ 采样线性映射）                          │
│              │                                                             │
│ ▶ FM1  M  S  │  ████████████        ██████                                 │
│ ▶ FM2  M  S  │      ██████████████████████                                 │
│ ▶ FM3  M  S  │           ████████        ██████                            │
│   FM4  M  S  │  ██████                                                     │
│   FM5  M  S  │                                     ████████                │
│   FM6  M  S  │                                                             │
│   FM7  M  S  │         ████████████                                        │
│   FM8  M  S  │                                                             │
│ ── 全局 ──   │  LFO: ▂▂▃▃▄▄▃▃▂▂   Noise: ────────                        │
├──────────────┴─────────────────────────────────────────────────────────────┤
│ lane 区（可展开）：PMS / AMS / PAN / TL(ch)                                 │
├────────────────────────────────────────────────────────────────────────────┤
│ 状态栏：pitch: opm-kc-kf/v1   grid: 假设 120BPM (参考)   unhandled: 0        │
└────────────────────────────────────────────────────────────────────────────┘
```

### 2.1 走带条

| 元素 | 行为 |
|---|---|
| ▶ / ■ / ⏸ | 播放 / 停止 / 暂停 |
| ⏮ / ⏭ | 跳到开头 / 跳到结尾 |
| 采样位置显示 | `mm:ss.mmm`，值直接来自 `GetCurPos(PLAYPOS_SAMPLE)` |
| 网格开关 | 关 / 1/4 / 1/8 / 1/16 / 1/32。**默认关** |
| 缩放滑块 | 像素/采样比例，线性 |

**没有 BPM 输入框。** 若要显示网格，BPM 由 `IGridMapper` 假设一个值，且必须在网格开关旁标注"假设"。

### 2.2 通道列表

每行：

```
[▶] 通道名  [M] [S]  ← 选中高亮
```

- `▶`：该通道当前是否有音在响（可选，需要分析 `atSample` 与播放位置）
- `M` / `S`：静音 / 独奏（仅影响播放，不影响数据）
- 通道名：YM2151 为 `FM1`~`FM8`；其他芯片按 `chips[].capabilities` 生成

### 2.3 时间轴

- 横向：`x = (sample - viewStartSample) * pxPerSample`
- 纵向：通道行高固定（如 28px），音符在行内按参考音高做小范围垂直偏移（±8px），**不画成真正的钢琴键盘**
  - 理由：YM2151 的 8 个 FM 通道各自都能演奏全音域，画成钢琴键盘会撞在一起。音高信息用"行内偏移 + 音名标签"表达
- 音条：圆角矩形，左端 = `startSample`，右端 = `endSample`
- 音条内标签：`C#4`（来自 `view.nearestNote`），若 `exact == false` 则标签加 `~` 前缀
- 音条边框：`exact == false` 时用虚线/半透明

### 2.4 网格线（参考，不吸附）

- 默认关闭
- 开启后按 `IGridMapper` 假设的 BPM 画等距竖线
- **不吸附**。要吸附必须显式开启，且吸附时 UI 必须提示"已量化显示，数据未改"

### 2.5 lane 区

折叠在通道行内（行高不够时展开成独立区域）：

| lane | 数据来源 | 画法 |
|---|---|---|
| PMS | `channels[].lanes[param=pms].points` | 阶梯折线 |
| AMS | 同上 | 阶梯折线 |
| PAN | 同上 | 水平条（L/C/R 分色） |
| TL(ch) | 从 `notes[].segments` 提取 `0x60+slot` 的载波值 | 折线 |

lane 里的点存**原始寄存器值**（0-127 等），y 轴不标"dB"或"百分比"。

## 3. 悬停与诊断

悬停音条时显示：

```
FM3  note C#4 (参考, exact=false, +12c)
  start  13230 samples  (00:00.300)
  end    22050 samples  (00:00.500)
  KC=0x2E  KF=0x1A
  regs: 0x20=C7  0x28=2E  0x30=1A  0x60=01  0x08=78
```

**必须显示原始寄存器值**。这是"这是推测"的诚实性要求，不是可选装饰。

状态栏常驻显示：

```
pitch: opm-kc-kf/v1   grid: 假设 120BPM (参考)   unhandled: 0
```

## 4. 音色编辑器（抄 furnace insEdit）

### 4.1 布局（照 furnace 的组织，不照抄代码）

Furnace 的 FM 编辑器（`src/gui/insEdit/insTabFM.cpp` 3644 行）不是"每个 operator 一个页签"，而是**一张宽表**：每行一个 operator，列是各项参数。

```
┌──────────────────────────────────────────────────────────────────┐
│ 音色 #3  [OPM ▾]   [打开 .fui]  [保存 .fui]                       │
├──────────────────────────────────────────────────────────────────┤
│ 算法 [4 ▾]   反馈 [5 ▾]   PMS [3]   AMS [0]                       │
├──────────────────────────────────────────────────────────────────┤
│ OP │ AR  DR  SR  RR  SL  TL  KS  MUL  DT1  DT2  AM  │
│ 1  │ 31  8   4   6   2   0   1   2    3    0    0   │
│ 2  │ 31  6   4   6   2   8   1   1    0    0    0   │
│ 3  │ 31  8   4   6   2   0   1   2    3    0    0   │
│ 4  │ 31  6   4   6   2   0   1   1    0    0    0   │
├──────────────────────────────────────────────────────────────────┤
│ [算法图：4 个方块 + 连线，显示哪些是载波]                          │
└──────────────────────────────────────────────────────────────────┘
```

### 4.2 `.fui` 直接输入

furnace 的 `.fui` 是**二进制块格式**（不是 JSON）：

```
"FINS" | u16 engineVersion | u8 type | u8 0
  [ "NA" | u16 len | 名字 ]
  [ "FM" | u16 len | FM 参数 ]
  ...
  "EN"
```

FM 块字段（`instrument.cpp:979-1025`）：

| 字节 | 内容 |
|---|---|
| 0 | op enable 位 + opCount |
| 1 | `(alg & 7) << 4 \| (fb & 7)` |
| 2 | `(tremLFO << 5) \| (ams & 3) << 3 \| (fms & 7)` |
| 3 | `(fmsLFO << 7) \| (amsLFO << 6) \| (ops == 4) << 5 \| (opllPreset & 31)` |
| 4 | `block & 15` |
| 5+ | 每 operator 8 字节（ksr/dt/mult, sus/tl, rs/vib/ar, am/ksl/dr, egt/kvs/d2r, sl/rr, dvb/ssgEnv, dam/dt2/ws） |

**实现方式**：直接链接 furnace 的 `instrument.cpp`，调 `DivInstrument::readInsData()`。不自己解析。

### 4.3 音色映射器（步骤 3）

界面：

```
┌──────────────────────────────────────────────────────────────────┐
│ 音色映射：YM2151 → YM2413                                         │
├──────────────────────────────────────────────────────────────────┤
│ 源音色 #3 (OPM, alg=4, 4-op)                                     │
│   ↓ 自动匹配                                                      │
│ 目标音色：OPLL preset #7 "Flute"   匹配度 0.72                    │
│   [手动改选 ▾]   [微调音量 TL: 0 ──●── 15]                        │
├──────────────────────────────────────────────────────────────────┤
│ 丢弃的参数：DT2, D2R, RS, ALG(降为 SUS 位)                        │
│ 降精度的参数：AR 31→15, DR 8→4, TL 0→3                            │
└──────────────────────────────────────────────────────────────────┘
```

"丢弃/降精度"清单直接对应 `GOAL.md` §6 的位宽表。**必须展示**（有损报告比"转换成功"更重要）。

## 7. 快捷键

| 键 | 动作 |
|---|---|
| `Space` | 播放 / 暂停 |
| `Home` / `End` | 跳到开头 / 结尾 |
| `←` / `→` | 按一个"参考网格"单位前后移动播放头（无网格时按 1000 采样） |
| `鼠标滚轮` | 缩放时间轴 |
| `中键拖动` | 平移时间轴 |
| `Ctrl+Roller` | 缩放通道行高 |
