# 测试用 VGM

本目录存放导入用的原始 `.vgm`，按 游戏/平台 分文件夹。

## 当前曲目集

`Spindizzy_II_(Sharp_X68000)/` —— 41 首，全部是 YM2151（OPM）×1 / 4 MHz。

其中 `31 Grass Maze.vgm` 是最早用来验证的那首：

| 项 | 值 |
|---|---|
| 芯片 | YM2151（OPM）×1，4 MHz |
| 总长 | 2,406,316 采样（54.6 s @44100） |
| note 数 | 2515（8 通道） |
| 特征 | 8 通道全用、ALG 覆盖 0/2/3/5 四类、载波 ML 有 1/2/4/8/10 五种 |

## 格式要求

- 标准 VGM 1.5x（**非** `.vgz` 压缩包）
- 单芯片或含 YM2151 的多芯片文件都能导入；非 YM2151 的写会完整落到 `orphans`，不丢
- 立体声/单声道均可

## GD3 标签

导入与转换全程透传文件的 GD3 标签（曲名/作者/游戏名），
成品的 `song.ym2413.vgm` 与原版 `song.ym2151.vgm` 标签一致。
